## 叙事和结构（已定）

- **明信片叙事**：每个项目是一张明信片，正面是图片或场景，背面是文字（标题加一段话），方便找工作时阅读。
- **流程**：名片 → 明信片叠层主界面 → 详情页。
- **叠层**：单点居中透视，后面的层只画黑色线框，每个项目占一层。最后一层是简历/目录页，正面是作品列表，背面是履历。左侧是黑白小方块的 dock，简历那一格单独、略高。
- 灵感来自电影 Her 的层叠界面，Jason 很在意层与层之间的空间感。

## 当前实现（v15）

1. **开场**：白底中间放 `namecard.jpg`（Jason Xuan / 宣家诺 / Cambridge | Ningbo / 2001.04.25 / jianuoxuan@gmail.com），阴影很淡。点击后，一层空白纸纹盖住文字，名片平滑放大到第一张明信片的大小和位置，然后图片淡入。
2. **主界面**：
   - 滚轮或方向键切换层，dock 可以直接跳到某一层。
   - 鼠标在空白处时，整叠（卡片加线框）会很轻、很慢地随鼠标倾斜，消失点也跟着移动。鼠标在卡片上时完全不动（Jason 说会晕）。
   - 卡片有一条很薄的不规则纸边，左上方有光，带淡阴影，边缘有极细的不规则缺口（没有折角）。
3. **Image / Text 开关**（右上角，只在主界面出现）：整叠在原位交叉淡入淡出，切换到文字面。不翻转，不要翻面动画。文字面是纸纹底，右下角有 +。简历层的文字面是履历，可以滚动。
4. **详情页**（点 + 或点卡片进入）：
   - 卡片原地放大到屏幕中间，其余页面从右边进来。
   - 从 Image 进入，顺序是“图片 → 文字页 → 其他图”；从 Text 进入，顺序是“文字页 → 图片 → 其他图”。
   - 滚轮上下都是左右滑，也可以拖动或用方向键。
   - 顶部中间是页码刻度：每页一根短竖线，当前页那根变长；没开始滑的时候，下一根会轻轻跳动。
   - 退出用 Esc 或回车，右上角的 × 也保留着。退出时卡片缩回原位，背后的叠层模糊、变淡。
5. **简历层**：纯白，不用纸纹，沿用旧网站的时间线排版。hover 作品行时，项目图片跟着鼠标出现，比最早的版本稍大（280px，竖图 180px）。

## Jason 的规则（必须遵守）

- 全站白底黑线框，黑白界面。动画必须流畅，只动 transform 和 opacity。
- 最多 2 种字体（目前只用 Geist），3 个字号：大标题、标题、正文。字级层次越少越好。
- 明信片是平的画框：没有白边，没有窗口阴影，hover 时图片不动。不要邮戳、编号、灰色标签。
- + 号不加圆圈，hover 或点击时旋转。× 不加红圈。
- **已否决**：hover 背景变色（纯色和渐变呼吸光都试过，都不要）、声音（太吵太吓人）、卡片翻面动画（“很假”，偏轴拟真版也不要）、折角（“太难看”）、跟着鼠标的透视过度灵敏、详情页图片下面放说明文字。
- Jason 习惯用中文，喜欢先讨论再动手，反馈通常一次说很多点。
