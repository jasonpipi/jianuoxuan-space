# Homepage demos (redesign, Nov 2026)

Snapshots of the homepage interaction demos. Each folder is self-contained: open `index.html` in a browser.

- `postcard-stack-2.0/`: business card → postcard layers → detail pages (v15). Handoff notes are in `handoff.md`.
- `postcard-stack-3.0/`: layers seen square-on with the vanishing point above centre, fog and camera travel between layers, each card a 3D paper box, text page scales like a picture. The panel at bottom right switches the depth ideas. Archived on 2026-11-13, before the pile and canvas views were added.
